# ThatDataPurple.Chrome
A purple theme for Chrome, Edge and Brave in the That Data Person brand colours, by That Data Person Limited.

## Screenshot
![Screenshot of ThatDataPurple theme applied to Chrome](https://github.com/thatdataperson/ThatDataPurple.Chrome/blob/main/images/ThatDataPurple.preview.png?raw=true)

## 2026 refresh
The theme now follows the That Data Person branding: a deep brand-dark (`#0D0629`) window frame and background tabs, a brand purple (`#4320CC`) toolbar and selected tab with white text, and a dark address bar.

Tab, toolbar and address bar text all meet WCAG 2.2 AA (at least 4.5:1). The colours are generated from the shared palette in [ThatDataPurple](https://github.com/thatdataperson/ThatDataPurple/tree/main/palette); see its contrast report for the numbers.

## Supported Versions
- Chrome 96+
- Microsoft Edge
- Brave, and other browsers built on Chromium that install themes from the Chrome Web Store

## Install
[ThatDataPurple.Chrome](https://chrome.google.com/webstore/detail/thatdatapurplechrome/eikanpoghdlfifddajgjlfahfoodipjo) is published on the Chrome Web Store.

- **Chrome and Brave:** open the store page and select *Add to Chrome* (Brave shows the same button).
- **Edge:** open the store page, select *Allow extensions from other stores* when Edge asks, then *Get*.

To install from this repo instead, copy the `chrome-theme` folder somewhere permanent, open `chrome://extensions` (`edge://extensions`, `brave://extensions`), turn on *Developer mode*, select *Load unpacked* and choose the folder.

## Uninstall
[Google](https://support.google.com/chrome_webstore/answer/148695?hl=en) provide detailed instructions on how to remove themes. In Edge and Brave, choose the default theme under *Settings > Appearance*.
